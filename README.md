# 🖨️ MaoneArt Print — Epson USB OTG Print Studio

Aplikasi Android (Tablet & Smartphone) untuk mencetak dokumen **PDF**, foto **JPG / PNG / WebP**, serta **Catatan / Struk** secara langsung ke printer **Epson** hanya menggunakan **Kabel USB OTG** tanpa memerlukan PC atau Wi-Fi.

## ✨ Fitur Utama
1. **Direct USB OTG Epson Engine**:
   - Deteksi otomatis Vendor ID Epson (`0x04B8`) & USB Printer Class (`Class 7`).
   - Mendukung protokol **ESC/P-R** (Epson Inkjet/EcoTank L120, L121, L1110, L3110, L3210, L3250, L805, dll.), **ESC/P2** (Universal Inkjet/Stylus), dan **ESC/POS** (Thermal Kasir 58mm & 80mm).
2. **Buka File PDF, JPG, PNG & Pilih Halaman**:
   - Render semua halaman PDF dengan pratinjau tajam.
   - Bebas centang/pilih halaman mana saja yang mau dicetak, pilih rentang halaman (`1-3, 5`), halaman ganjil/genap, putar 90° per halaman, atau tambah banyak foto sekaligus.
3. **Mode Tablet Split-View & Smartphone**:
   - Tampilan 2 panel otomatis di layar Tablet untuk kemudahan memilih halaman sambil mengatur kertas.
4. **Integrasi Android System Print Service & Share Intent**:
   - Muncul otomatis di menu **Cetak / Print** sistem Android maupun menu **Buka Dengan / Bagikan** dari WhatsApp, Galeri, dan File Manager.
